# Project Instructions

Before adding or changing any UI in Hendle, read `docs/DESIGN_SYSTEM.md`.

The current design language is part of the product contract:

- keep the strict editorial style with thin lines, square surfaces, restrained semantic color, and display serif type for important objects and metrics;
- reuse the tokens in `src/styles/main.css` instead of adding one-off colors, spacing, borders, fonts, or shadows;
- if the design direction changes, update `docs/DESIGN_SYSTEM.md` and apply the change consistently across the whole app, not only in one new component;
- verify light and dark themes after visual changes.

For future Codex work in this repository, treat `docs/DESIGN_SYSTEM.md` as the source of truth for visual decisions.
